The Julia package ecosystem, as a graph

Every registered package, its dependencies, GitHub metadata, and commit authors — one queryable RDF dataset. Runs entirely in your browser; nothing is sent anywhere.

Loading the graph (one-time, ~4 s)…

Identifiers are real URLs — package nodes are JuliaHub pages, people are GitHub profiles, licenses are SPDX entries — so any IRI in your results is a clickable link (literals like counts and names are plain text). The full dataset is a single N-Quads file (… triples) built by an open pipeline. Prefixes jl:, rdfs:, dcterms:, foaf:, sdo:, xsd: are predeclared.
